## Топология prod

```
браузер ──HTTPS──> nginx MAGTRANS ──HTTP:80──> Caddy (наш сервер) ──> api / web
                   (TLS, сертификат)             │
                                                 └─ /api/*, /health, /ready → api
                                                    остальное → web
```

- TLS снимает корпоративный nginx, у нас ACME нет вообще.
- `TRUST_PROXY_HOPS=2` (nginx + Caddy), на pre-prod — `1`.
- Выкат: GitHub Actions → self-hosted runner прямо на сервере (входящие порты не нужны).

## Как выполнять

Каждое действие на сервере, в GitHub или Google идёт через
`preprod-parity-agent`: он выдаёт шаг, а после подтверждения записывает
результат в `docs/27`. Секреты не пишутся ни в заметки, ни в журнал, ни в
чат — только «задан, лежит в 1Password → <запись>».
